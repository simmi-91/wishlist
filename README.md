# Wishlist Frontend

React + Vite + TypeScript admin panel for the wishlist service and the gift log. All pages except the front page require a Google login, and every API call sends the app token as a bearer token.

Live at https://admin.3lin.no/wishlist/ (the app is built with `base: "/wishlist/"`).

## Features

- **Preview** (`/preview`) – all wishes as cards, with an active/inactive toggle.
- **Add & Edit** (`/edit`) – create and edit wishes with a Quill rich text description; images can be uploaded, attached from a URL or picked from the gallery. Leaving the editor with unsaved changes asks for confirmation.
- **Gift log** (`/giftlog`), three tabs:
    - **Registrer** – register gifts and gift ideas, with quick choices and a Christmas mode (pick the year, suggests givers/recipients from the last two registered Christmases).
    - **Historikk** (`/giftlog/history`) – search and filter gifts; the filters live in the URL, so bookmarks and the back button keep them.
    - **Oversikt** (`/giftlog/overview`) – open gifts per status, given/received per year (collapsible, the two latest years open) and person admin (name, household, number of gifts; a person can only be deleted when no gift uses it).

## Stack

- React 19, Vite, TypeScript
- @tanstack/react-router (file-based routing), @tanstack/react-query (data)
- react-bootstrap + Bootstrap 5.3, bootstrap-icons
- @react-oauth/google (Google login), zustand (unsaved changes flag)
- react-quill-new (rich text)
- ESLint + TypeScript project refs

## Running the app

```bash
npm install
npm run dev
```

Other scripts:

- `npm run build` – type-check then bundle to `dist/`
- `npm run preview` – preview the production build
- `npm run lint` – lint all sources

## Environment

`npm run dev` runs Vite in `dev` mode and reads `.env.dev`; `npm run build` reads `.env` / `.env.production`. Both need:

```
VITE_API_BASE_URL=<backend-url>
VITE_GOOGLE_CLIENT_ID=<gis-client-id>
```

## Deploy

`.github/workflows/deploy.yml` runs on push to `main` and manually from the Actions tab. It builds with `.env.production` written from repository secrets, copies `dist/` to `/var/www/admin/client/wishlist` on the server (the previous build is kept as `wishlist_old`) and checks that https://admin.3lin.no/wishlist/ answers.

Repository secrets: `VITE_API_BASE_URL`, `VITE_GOOGLE_CLIENT_ID`, `SERVER_HOST`, `SERVER_USER`, `SERVER_SSH_KEY`.

## Structure

- `src/routes/` – one file per route; `src/routeTree.gen.ts` is generated by the router plugin, don't edit it
- `src/auth/` – `AuthProvider` (Google login → app token, kept in localStorage), `ProtectedRoute`
- `src/api/` – `client.ts` (base URL + bearer token) and endpoints for wishlist, images and gift log
- `src/hooks/` – React Query hooks per area, `usePendingChanges` (zustand)
- `src/components/` – feature components (wish editor, images, gift log) and `layout/` (header, nav)
- `src/types/`, `src/utils/` – shared models and helpers
- `src/index.css` – global styles. It is imported before Bootstrap in `App.tsx`, so overrides of Bootstrap classes need higher specificity (e.g. `.form-control.my-class`)
